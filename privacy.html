AI Deal Hunter

Privacy Policy

Effective October 28, 2026

Summary

AI Deal Hunter is a personal tool used only by its owner, on the owner's own computer. It reads the owner's own Gmail with read-only access to find offers and promotions. Gmail data stays on that computer. This app never sells it, never uses it for advertising and never uses it to train AI models.

Data accessed

With the owner's consent, the app uses the Google permission https://www.googleapis.com/auth/gmail.readonly. It reads only messages that match offer-related search queries, such as promotional, bank, credit-card and cashback offers from roughly the last 14–30 days. Messages about security codes, passwords and sign-ins are excluded by those queries.

For each matching message it reads:

  • sender, subject and date
  • body text, capped at 20,000 characters
  • links in the body
  • Gmail labels and thread ID

The app cannot send, delete, label, archive or otherwise change email, and it does not request access to contacts, calendars or files.

How the data is used

Only to show the owner deals, promotions and offers that may be worth acting on. That means sorting messages by likely value, comparing them with offers found elsewhere, and keeping a research history. Nothing is done automatically on the owner's behalf: the app never purchases, applies, replies or contacts anyone.

Storage and security

  • Gmail data is stored in a local database on the owner's computer. It is not uploaded to any server operated for this app; no such server exists.
  • The Google authorization token is stored in a local file readable only by the owner's Windows account. It is never shared or published.
  • The owner can disconnect at any time, either in the app or at myaccount.google.com/permissions. Deleting the app's data folder removes all stored email content.

Sharing and AI processing

Gmail data is not sold, rented or shared with anyone, and it is not used for advertising.

When the owner asks the app's built-in research assistant a question, the relevant stored records may be sent to Anthropic's Claude AI service so it can answer. This happens only for features the owner requests and controls, under the owner's own Anthropic account, terms and privacy settings. The app itself never uses Gmail data to train or improve AI models.

No people read the data other than the owner.

Google API Services User Data Policy

AI Deal Hunter's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Stored messages are kept until the owner deletes them. Revoking Google access stops all further reading immediately. Deleting the local data folder removes everything the app has stored.

Changes and contact

If this policy changes, the effective date above will be updated. Questions can be raised through the issue tracker of the repository that hosts this page.
